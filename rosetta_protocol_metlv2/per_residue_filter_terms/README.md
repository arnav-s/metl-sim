# Per-Residue Filter Terms

## All PerResidueRealMetrics from Rosetta Docs

| Metric | Status | What It Does | Global Filter Mapping                                                                                                                                                                                                                                                                                                                                                                                                                                                  | Reason                                                                                                                             |
|--------|--------|--------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|------------------------------------------------------------------------------------------------------------------------------------|
| PerResidueSasaMetric | ✅ Included | Solvent accessible surface area (Å²) per residue in the folded structure. | TotalSasa (total_sasa, exposed_total). The filtered global terms — exposed_hydrophobics, exposed_polars, ExposedHydrophobics (exposed_np_AFIMLWVY), BuriedSurfaceArea (buried_all, buried_np), some have no direct per-residue analog because they filter by residue type or compute reference-minus-folded SASA. However, these global terms are sums over per-residue contributions, so the model can recapitulate them from per-residue SASA + amino acid identity. | Core structural feature for burial/exposure classification.                                                                        |
| HbondMetric | ✅ Included | Count of hydrogen bonds each residue makes with any other residue. | BuriedUnsatHbonds (unsat_hbond) — inverse signal: BuriedUnsatHbonds counts missing H-bonds on buried residues, this counts H-bonds made. Combined with SASA, the model can learn buried + few H-bonds = unsatisfied. Same idea as above, per residue requires some learning to get the global metric.                                                                                                                                                                  | Captures per-residue hydrogen bond satisfaction; complement to global BuriedUnsatHbonds.                                           |
| SidechainNeighborCountMetric | ✅ Included | Cone-based weighted sidechain neighbor count along the CA→CB vector. | AverageDegree (degree_core, degree_core_boundary, degree). Global filters restrict by core/boundary via task operations; same as above, per-residue values make the model learn those boundaries directly. Then it can figure out which are core, boundary, etc.                                                                                                                                                                                                       | Per-residue replacement for AverageDegree; direction-aware burial metric superior to simple distance counting.                     |
| PerResidueClashMetric | ✅ Included | Count of atomic steric clashes per residue based on Lennard-Jones radii overlap. |                                                                                                                                                                   | Mostly zeros on relaxed structures but computationally free; flags real problems when mutations are clashing.                      |
| PerResidueSapScoreMetric | ✅ Included | SASA × hydrophobicity per residue. | ExposedHydrophobics (exposed_np_AFIMLWVY), SAP captures the same concept — exposed hydrophobic surface — but with spatial context from the [5 Å neighborhood](https://docs.rosettacommons.org/docs/latest/rosetta_basics/scoring/sap-constraint) per residue.                                                                                                                                                                                                          | Context-aware hydrophobic exposure metric; captures clustering of exposed hydrophobic patches, not just individual exposure.       |
| PerResidueEnergyMetric (hydrophobicity) | ✅ Included | Per-residue reference energy using custom hydrophobicity weight files (version1 and version2). | ScoreType (total_hydrophobic, total_hydrophobic_AFILMVWY) — direct per-residue decomposition of the same score functions.                                                                                                                                                                                                                                                                                                                                              | Pure amino acid identity lookup — model could learn this from sequence alone, but included for now.                                |
| PeptideInternalHbondsMetric | ❌ Tested, removed | Counts non-local hydrogen bonds excluding sequence-nearby residues. | No direct global analog.                                                                                                                                                                                                                                                                                                                                                                                                                                               | Returns a single global value despite being listed in PerResidueRealMetrics docs; not actually per-residue.                        |
| PerResidueDensityFitMetric | ❌ Tested, removed | Measures fit of each residue's atoms to an experimental electron density map. | No global analog.                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Requires an experimental density map from X-ray crystallography or cryo-EM; not applicable to computational models.                |
| PerResidueBfactorMetric | ⬜ Not tested | Reads the B-factor from the PDB file for a given atom (default CA) per residue. | No global analog.                                                                                                                                                                                                                                                                                                                                                                                                                                                      | B-factors are experimental data stored in PDB files from crystallography; Rosetta-relaxed models do not have meaningful B-factors. |
| PerResidueRMSDMetric | ⬜ Not tested | Per-residue RMSD between the input structure and a reference structure. | No global analog.                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Requires a reference/native structure to compare against; not applicable when scoring single designs in isolation.                 |
| CurrentProbabilityMetric | ⬜ Not tested | Returns the ML-predicted probability of the current amino acid identity at each position. | No global analog.                                                                                                                                                                                                                                                                                                                                                                                                                                                      | ML-based metric (requires ProteinMPNN/ESM); outside scope of physics-based Rosetta features.                                       |
| ProbabilityConservationMetric | ⬜ Not tested | Shannon entropy from ML-predicted amino acid probabilities at each position. | No global analog.                                                                                                                                                                                                                                                                                                                                                                                                                                                      | ML-based metric (requires ProteinMPNN/ESM); outside scope of physics-based Rosetta features.                                       |
| PTMPredictionMetric | ⬜ Not tested | Predicts probability of post-translational modifications at each position. | No global analog.                                                                                                                                                                                                                                                                                                                                                                                                                                                      | ML-based metric; outside scope of physics-based Rosetta features.                                                                  |
| WaterMediatedHbondMetric | ⬜ Not tested | Counts hydrogen bonds bridged through explicit water molecules per residue. | No global analog.                                                                                                                                                                                                                                                                                                                                                                                                                                                      | Requires explicit water molecules modeled in the structure; Rosetta-relaxed models typically do not include explicit waters.       |

## Global Filter Terms With No Per-Residue Analog

| Global Filter | Names | Why No Per-Residue Version                                                                                                                                                                                                                                                                                                                        |
|---------------|-------|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| PackStat | pack | Whole-structure probe-based cavity detection; no per-residue SimpleMetric exists. Captures underpacking (complementary to PerResidueClashMetric which captures overpacking).                                                                                                                                                                      |
| SecondaryStructureHasResidue | one_core_each, two_core_each, ss_contributes_core | Per-secondary-structure-element check, not per-residue. Verifies each helix/sheet has hydrophobic core residues.                                                                                                                                                                                                                                  |
| SSPrediction | ss_mis (removed for timing) | Global secondary structure mismatch probability. Not per-residue and removed from pipeline for timing reasons.                                                                                                                                                                                                                                    |
| ResidueCount | res_count_all, res_count_buried_core, res_count_buried_core_boundary, res_count_buried_np_core, res_count_buried_np_core_boundary | No per-residue analog, but can easily be recapitulated from per-residue SASA (for burial classification) and amino acid identity (for hydrophobic filtering). res_count_all is simply the length of any per-residue feature vector.                                                                                                               |
| AtomicContactCount |contact_all, contact_buried_core_boundary, contact_buried_core | Count all atom–atom pairs in the pose separated by ≤ 4.5 Å. There is no per residue atomic count.  PerResidueClashMetric and SidechainNeighborCountMetric give an idea of the density and if there are atomic clashes. But not per direct Atom counts.  |
